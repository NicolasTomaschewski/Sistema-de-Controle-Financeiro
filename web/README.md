# Frontend — Controle Financeiro

Interface React + TypeScript (Vite) para o sistema de controle financeiro. Consome a API Go via cookies de
sessão HttpOnly e CSRF (double-submit cookie).

Consulte o [README principal do projeto](../README.md) para instruções completas de configuração,
execução e testes do sistema como um todo.

## Comandos

```
npm install     # instalar dependências
npm run dev     # servidor de desenvolvimento em http://localhost:5173 (com proxy para a API em :8080)
npm run build   # verificação de tipos + build de produção em dist/
npm run preview # servir o build de produção localmente
```
